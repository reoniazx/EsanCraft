# Noto Sans Lao

Unmodified regular and bold hinted TrueType fonts from the Noto Project Authors,
licensed under the SIL Open Font License 1.1 (see `OFL.txt`).

Source: https://github.com/notofonts/lao/releases/tag/NotoSansLao-v2.003
Archive: https://github.com/notofonts/lao/releases/download/NotoSansLao-v2.003/NotoSansLao-v2.003.zip
Files extracted from `NotoSansLao/hinted/ttf/`; the license is the archive's
`OFL.txt`, with trailing whitespace removed.

Embedded as fallback fonts for Lao text on every platform, including Web/WASM.
The license is also embedded in the About window for packaged distributions.

Use this release rather than the legacy `noto-fonts` archive: the legacy Lao
fonts omit Lao Pali letters such as U+0E86. Glyph regression tests cover assigned
Lao letters, combining marks and digits, including U+0ECE.
